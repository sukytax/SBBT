# 🧾 SBBT – Split Bill Bareng Teman

**SBBT** adalah aplikasi kalkulator tagihan yang **minimalis, transparan, dan adil**.
Dirancang untuk memudahkan perhitungan pengeluaran bersama saat makan bareng,
nongkrong, atau belanja kelompok, tanpa ribet hitung manual.

## ✨ Kenapa SBBT?

- **Minimalis** – Tampilan bersih dan simpel, langsung bisa dipakai tanpa belajar.
- **Transparan** – Setiap perhitungan bisa dilihat jelas, tidak ada angka misterius.
- **Adil** – Setiap orang hanya membayar sesuai pesanannya, termasuk porsi pajak, service, dan diskon.

## 🎯 Cocok Untuk

- 🍜 Makan bareng di restoran atau kafe
- ☕ Nongkrong dan patungan
- 🛒 Belanja kelompok
- ✈️ Pengeluaran liburan bersama

## 🚀 Fitur

- Tambah peserta dan item pesanan dengan mudah
- Bagi item secara merata atau per orang
- Pembagian otomatis untuk pajak, service charge, dan diskon
- Rincian total per orang yang jelas
- *(tambahkan fitur lain di sini)*
